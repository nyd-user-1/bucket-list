The AWS CLI isn't installed

Bucket List reads S3 through the AWS CLI (v2). Install it, then sign in:

brew install awscli      # or the installer from aws.amazon.com/cli
aws configure            # access keys
aws sso login            # or an SSO profile

AWS credentials aren't working

The CLI is installed, but aws sts get-caller-identity failed:


    
Sign in with one of these, then check again. The app reads the default profile, or the one named by AWS_PROFILE when launched from a terminal.

    
aws configure            # access keys
aws sso login            # SSO session

  

  

    
Bucket List needs list permissions only: s3:ListAllMyBuckets, s3:GetBucketLocation, s3:ListBucket, and cloudwatch:GetMetricData for the cost estimate. It never downloads or modifies an object.
