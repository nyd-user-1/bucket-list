Read-only, end to end.

Four steps, each a plain AWS CLI call. Names, sizes, and dates only: no object is downloaded or modified.

Discover
bucket-listevery bucket, its region
›S3APIlist-buckets
›S3APIget-bucket-location, per bucket
›STSget-caller-identity
● inaccessible buckets are skipped with a warning
Estimate
bucket-listobjects, bytes, $/month
›CLOUDWATCHget-metric-data, 50 buckets per call
›PRICEper storage class, list prices
›ASKProceed? [y/N]
● about five cents per 10 million objects
Sweep
bucket-listfolders split into parallel walks
›S3APIlist-objects-v2 --delimiter /
›S3ls --recursive, streamed, for deep or wide folders
›POOL12 concurrent calls across all buckets
● Glacier objects list without a restore
Render
bucket-listone self-contained file
›PAGESaccount → bucket → folder
›FAMILIESIMG_#.jpg ×1,240,118, digits collapse to #
›VERSIONSflags buckets hiding old versions
● works offline, light and dark
no sdk · no ai · no telemetry · nothing modified
